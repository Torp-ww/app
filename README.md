# Семейный помощник: скачать

Приложение для семьи на Android: финансы, история доходов и расходов, статусы родных и общий календарь.

**[Скачать последнюю версию](../../releases/latest)**: нажмите на файл `semeiny-pomoshnik.apk` внизу страницы, затем откройте его на телефоне и разрешите установку.

Версия для iPhone пока не готова.
